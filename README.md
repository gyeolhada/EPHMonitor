# EPHMonitor

## Project Introduction
This project implements a multi-scenario physiological signal monitoring system based on an ear-worn device, specifically designed for real-time heart rate and respiratory rate monitoring during physical activity. To ensure both accuracy and real-time performance, the system leverages the occlusion effect and advanced signal processing algorithms, overcoming the limitations of traditional monitoring devices in dynamic environments. By integrating the ear-worn device with an Android app, users can obtain critical physiological data in real time during exercise, enabling scientific adjustment of workout intensity to avoid overexertion or injury. Additionally, the system incorporates music playback and navigation features, enhancing the overall exercise experience by seamlessly combining health monitoring with entertainment.

## Project Features
### Accurate Physiological Monitoring with Real-Time Feedback
Utilizing an ear-worn design and occlusion effect technology, the system enables real-time monitoring of heart rate and respiratory rate. It delivers precise data analysis and provides immediate feedback to help users adjust exercise intensity, effectively avoiding fatigue and potential injury.

### Personalized Health Management
Based on users’ exercise history, the system automatically recommends personalized workout plans and health suggestions, guiding users to scientifically tailor their exercise routines and intensity levels.

### Comfortable Wear and Enhanced Exercise Experience
The ergonomic ear-worn design ensures long-term comfort and convenience. In addition, integrated music playback and smart navigation features enhance rhythm during workouts and ensure safe and enjoyable exercise routes.
